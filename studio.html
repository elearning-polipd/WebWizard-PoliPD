5Terbitkan di GitHub Pages

Ikut panduan bergambar di bahagian Penerbitan untuk melihat butang yang perlu ditekan.

  1. 1Ekstrak laman-saya.zip.
  2. 2Di GitHub, tekan New, namakan repositori laman-saya, pilih Public.
  3. 3Tekan uploading an existing file, seret SEMUA fail dari dalam folder, kemudian Commit changes.
  4. 4Settings → Pages → Branch main / root → Save. Tunggu 1–2 minit.
